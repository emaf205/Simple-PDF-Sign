# Simple PDF Sign

**Firma PDF in pochi secondi, direttamente dal browser.**

Ho creato Simple PDF Sign perché mi serviva uno strumento essenziale: aprire un PDF, inserire la mia firma, posizionarla con il mouse ed esportare il documento.

**Niente account. Niente registrazioni. Niente upload dei file.**

## Come funziona

1. Trascina il PDF
2. Inserisci firma, timbro o immagine
3. Spostala e ridimensionala
4. Esporta il PDF

## Funzioni

- Drag & drop
- Firme, timbri e immagini
- Posizionamento con il mouse
- Ridimensionamento e rotazione
- PDF multipagina
- Esportazione immediata
- Elaborazione locale nel browser
